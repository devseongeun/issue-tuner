# README 개편 설계

## 목표

README에서 Issue Tuner의 현재 지원 범위와 처리 흐름을 빠르게 파악할 수 있게 한다.

## 변경 범위

- Issue Tuner가 Codex 기준으로 만들어졌고 현재 Codex를 지원한다고 명시한다.
- Claude 지원이 예정되어 있다고 밝힌다.
- AIOSS 과정과 목적에 관한 문장을 삭제한다.
- Mermaid 대신 저장소에 포함된 정적 SVG로 처리 흐름을 보여준다.
- 나머지 한국어 문장은 사실과 고유명사를 유지하면서 기계적인 나열과 번역투만 다듬는다.

## 흐름 이미지

이미지는 위에서 아래로 `Jira / Issue Report 입력 → 재현 → 진단 → 수정 → 독립 검증 → 게시 승인 요청`을 잇는다. 승인되면 `Draft PR/MR`로 이동한다. 승인되지 않으면 `요청 보완`을 거쳐 `게시 승인 요청`으로 돌아간다.

SVG는 밝은 배경, 단색 선, 짧은 레이블만 사용한다. GitHub의 밝은 테마와 어두운 테마에서 모두 읽을 수 있도록 색 대비를 확보하고 이미지 자체에 설명 가능한 `alt` 문구를 붙인다.
